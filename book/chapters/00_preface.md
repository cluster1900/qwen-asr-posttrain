## 为什么市面上的教程常常让人“一看就会，一跑就废”？

在真正把一个大模型（如本书贯穿剖析的 `Qwen3-ASR-0.6B`，或者你手里的 `Qwen3-8B`、`LLaMA-3`、`DeepSeek`、`Qwen2.5-VL`）从零训到能上线交付的过程中，新手最常撞上三堵高墙：

1. **第一堵墙：概念断层。** 数学教材只讲抽象公式，不讲它在 PyTorch 里长什么样；框架教程只教你调 `trainer.train()`，一旦显存爆了（`CUDA Out of Memory`）或 `loss` 变成 `NaN`，你就彻底抓瞎。
2. **第二堵墙：硬件盲区。** 不懂 GPU 的 SM、Warp、SRAM 和 HBM 带宽，就不明白为什么 FlashAttention 能把速度提高 3 倍、为什么 `batch_size=1` 时换更贵的卡推理反而没变快、也不知道为什么把 LoRA 学习率调成 `1e-6` 在 `bfloat16` 下竟然会导致 **99.7% 的参数根本没有更新**。
3. **第三堵墙：只讲理想，不讲踩坑。** 教程里的 SFT 和 DPO 似乎永远顺风顺水；可真实工程里，你把无标点数据喂进带标点先验的模型，30 步就能把模型训崩；你直接跑标准整句 DPO，静音音频居然会吐出莫名其妙的英文幻觉 `Human Rights Watch`；你辛辛苦苦跑了 23 组在线 RL，结果发现连严格的验证集门禁都过不了……

::: tip 本书的三条铁律
1. **绝不跳步**：每一个数学公式，先讲生活类比，再用 3 个以内的小数字手算一遍，再逐符号翻译成大白话，最后附上可直接运行的 PyTorch 代码。
2. **绝不纸上谈兵**：本书所有模型参数拆解、显存账本和 SFT → DPO → RL 后训练复盘，全部锚定在真实工程项目 `Qwen/Qwen3-ASR-0.6B`（精确到最后 1 个参数：`782,426,112`）的 NVIDIA A100 实测数据与真实踩坑日志上。
3. **举一反三**：学完标本模型后，第 12 章给你一套“任意模型 0-to-1 七步万能实战手册”，无论你明天想微调文本对话模型、代码模型、多模态视觉模型还是语音模型，都能照着同一套方法论从零跑通。
:::

## 全书阅读路线图

全书共分四大篇、十二章及三个速查附录，遵循“**直觉与地基 → 硬件与算子 → 模型逐层解剖 → 后训练与工程闭环**”的螺旋路径展开：

![图 0-1 全书 0-to-1 学习路线图](assets/diagrams/01_learning_roadmap.svg)

| 篇目 | 章节 | 你将彻底攻克的硬核问题 |
| :--- | :--- | :--- |
| **第一篇：地基与引擎** | 第 1–2 章 | 用高中函数搞懂反向传播与交叉熵；吃透 PyTorch 内存布局（Storage/Stride）、Autograd 计算图、Gradient Checkpointing 断链坑、BF16/FP32 浮点 ULP 下溢与 AdamW 余弦调度 |
| **第二篇：硬件与算子** | 第 3–5 章 | 看透 GPU 内部结构（SM/Warp/Tensor Core/HBM/SRAM）与 Roofline 性能屋顶线；掌握 GEMM、FlashAttention、RMSNorm、SwiGLU、RoPE、Fused CE 与 Triton 融合原理；精准手算任意模型训练/推理显存并选对显卡 |
| **第三篇：模型全解剖** | 第 6–8 章 | 逐层解剖 `Qwen3-ASR-0.6B` 的全部 782,426,112 个参数（128-bin Log-Mel → 3×Conv2d → 18 层 AuT 编码器 → Projector → 28 层 Qwen3 解码器 GQA/QK-Norm/SwiGLU），并掌握 3 行代码解剖任意 HuggingFace 模型的通用心法 |
| **第四篇：后训练闭环** | 第 9–12 章 | 从零推导并实战 LoRA、SFT、DPO、GRPO/RL 全链路；复盘标点先验冲突、DPO 配分函数偏移与直通差异掩码、`k3` KL 散度、Sim-to-Real 物理增强与配对簇 Bootstrap 统计检验；最后交付可复用于任意模型的 0-to-1 万能脚手架 |

### 给不同读者的阅读建议

- **高中生 / 刚转行的零基础读者**：请严格按第 1 章到第 12 章的顺序阅读。遇到手算例题时，强烈建议拿一张草稿纸跟着算两分钟——当你亲手算通第一个反向传播梯度和第一个 FlashAttention 分块累加时，你对大模型的恐惧感会瞬间烟消云散。
- **有开发经验、想快速上手微调项目的工程师**：可以先快速浏览第 1 章，精读第 2、4、5 章（PyTorch 陷阱、算子直觉、显存精算），然后重点啃透第 6–12 章的逐层解剖与 SFT/DPO/RL 实战。
- **正在调参炼丹、遇到 OOM / 幻觉 / 指标不涨的实战者**：随时翻阅 **附录 A（公式速查）** 与 **附录 B（OOM 与训练炸裂排错诊断表）**，再回到对应章节查看底层根因。
